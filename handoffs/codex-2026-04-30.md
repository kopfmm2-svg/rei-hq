## TASK 2 [P0] Worker secrets 設定

**目的**: Workerに必要な環境変数をCloudflare Secretsとして設定する

**前提**
- TASK 1（deploy）完了後に実行
- LINE Channel secret / access token は **再生成が必要**（古い値はチャットに貼ってしまい漏洩済み）
- 新しい値の取得方法: LINE Official Account Manager → Messaging API → Channel secret / Channel access token

**必須 secrets（wrangler secret put コマンドで設定）**

```bash
source ~/.nvm/nvm.sh
cd "/Users/matsubaramasayuki/Documents/New project"

npx wrangler secret put LINE_CHANNEL_ACCESS_TOKEN
# → プロンプトが出たら新しいトークンを貼り付け

npx wrangler secret put LINE_CHANNEL_SECRET
# → プロンプトが出たら新しいシークレットを貼り付け

npx wrangler secret put GITHUB_TOKEN
# → GitHubの Personal Access Token (repo権限つき) を貼り付け
```

**環境変数（wrangler.tomlに追記 or vars設定）**

```bash
npx wrangler secret put GITHUB_OWNER
# → kopfmm2-svg

npx wrangler secret put GITHUB_REPO
# → personal-brain
```

**オプション（後回し可）**
```bash
npx wrangler secret put LLM_API_KEY       # OpenAI APIキー（後で）
# LLM_MODEL=gpt-4.1-mini
# LLM_BASE_URL=https://api.openai.com/v1
```
